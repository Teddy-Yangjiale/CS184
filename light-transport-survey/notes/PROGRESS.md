## 0. 一句话结论

**"能算出好看的图"已经解决得很彻底；"能保证光源一变、图就按物理正确变化"几乎没人量化过。**
实时渲染一侧（ReSTIR / 神经缓存）根本不把光源参数放进网络，动态光靠每帧在线重训练 8–16 帧去"追"；前馈渲染一侧（RenderFormer）把光源参数化了，但训练分布极窄，越界失败是作者自己写明的。**中间那块"响应是否可靠"的空白，是真的空白。**

### C2 前馈神经渲染（4 篇）

- **RenderFormer V1（SIGGRAPH 2025）**：两阶段 transformer，直接吃三角网格出 GI 图，无 per-scene 训练。训练分布极窄：1–8 个**白色漫反射**三角光源、位于**场景外**、距离 2.1–2.7、强度 2500–5000、相机在场景外、512²。越界：>8 光源丢阴影/高光、**场景内光源直接错**、彩色光被忽略、镜面互反射 >3 次丢失。8×A100 训 8M 图。**代码 MIT + HF 权重**。
- **V2（ECCV 2026）**：稀疏注意力 + 异构图元，128K 图元 / 2048²，相机可进场景，支持折射/体积/环境光。仍限 **≤8 光源**；单帧训练无时序一致性；纹理固定 32×32。32×A100 训 19 天。官方代码库 `iamNCJ/RenderFormer-Studio`（44★，2026-09 更新）声明同时含 V1 与 V2 的数据/训练/推理代码；V2 权重在 HF `RenderFormer/renderformer-v2`（本机代理连 HF 失败，未逐一验证文件）。
- **RenderFormer++（2026）**：注入渲染方程归纳偏置，500K 场景 / 2M 图，8×A100 训 7 天；代码"接收后公开"。
- **LiNO（2026）**：**不是渲染论文**，是 PDE 神经算子，反射/折射/散射是隐空间算子的类比，无光源无图像。已从渲染簇剔除。

**簇级空白**：这条线把"光源参数 → 图像"学成了一个函数，但**只学了一个点附近的函数**；作者自己的越界实验就是"响应错误"的最好证据，却只做了定性展示（补充视频），没有一个量化指标。

### C4 波动光学渲染（4 篇）

- **Wave Ray (2023)**：把"光电探测态波函数"当广义光线，波动传输同时弱局域、线性、完备，可反向。1 spp 42–240 ms/帧。
- **Wave Tracing (2025)**：把 Veach 路径积分推广到双线性/弱局域形式，椭圆锥为本元，完整系统。1920×1080 @ 4k spp ≈ 1 h15m。**明确不能**：跨路径相干（无散斑）、谱样本间干涉；仍假设探测器时间平均。
- **GratNet (2025)**：MLP 隐式表示衍射 BRDF，压两个数量级，Mitsuba 3 延迟着色 5–8 fps。真值仅 Kirchhoff 标量远场 Fraunhofer，**网络无位置输入**，一个 patch 的 BRDF 整块复用。
- **Photon Guiding Caustics (2024)**：每光源在线学 3D 高斯混合，闭式方向采样消视差；不支持间接焦散。

**实现状态**：`ssteinberg/wave_tracer`（194★，2026-09 仍更新）是这条线唯一可跑的完整系统。**空白**：没有任何工作做"何时该用几何光学、何时该用波动光学"的误差驱动判据。

### C5 方法学基础

- **Sobolev Training (2017)**：值 + 导数联合监督，样本复杂度 K_sob ≤ K_reg（对高斯/分段线性族严格更小），低数据区收益最大；**反例**是高频起伏函数（Ackley）在数据少时反而更差。**原文没有做任何噪声/误差分析**——所以不能引它来为"有限差分监督"背书。
- **Neural Integral Operators (2025)**：把去噪提前到着色前，材质无关去噪，单帧实时。
- **NPM Path Guiding (2025)**：多分辨率特征网格 + vMF 混合在线学分布，2M 参数，评估 3 ms/帧。

### C6 光镊物理（2 篇，用来校准隐喻）

- **κ 的定义**：势阱在平衡点的曲率，`F = −κr`，`V = ½κr²`。两篇实测一致。
- **测量**：频域（BFPI + QPD，拟合 PSD 角频率 `f_c = κ/(2πγ)`）或时域（荧光强度自相关，拟合 `τ = γ/κ`）。**两条路等价。**
- **与势阱形状**：谐近似只在 `r ≪ ω`（光斑 1/e² 宽）成立；κ 越大阱越窄、布朗振幅 `√(k_BT/κ)` 越小；κ ∝ 功率。
- **捕获范围**：**两篇都没有给解析式**，只能读到"由光斑/间隙尺寸决定"。→ 这其实是个提醒：把"捕获范围"直接搬到渲染，需要你自己定义，别假装有现成公式。
- **偏振控刚度**：线偏振使 `k_x ≠ k_y`（300 nm 球 49 vs 71 pN/µm）；圆偏振使各向异性消失（|s|<0.03）；对 >λ 颗粒，场重分布能让不对称**反号**（1 µm 球 s=−0.1）。

**这条对方向 A 的直接校准**：你上一轮写"图像导数 ≠ 力学刚度"是对的，但更准确的说法是——**刚度对应图像对参数的二阶导（Hessian/曲率），一阶导只对应"力/灵敏度"**。两篇实验都按 `V = ½κr²` 定义，等于确认了这一点。

## 4. 对你三个方向的判决

### 方向 A（扰动响应可靠的神经渲染）——空白仍在，但必须换命题

**支持空白的证据**：
1. 实时渲染一侧 7/8 篇不把光源参数放进输入，动态光只靠 8–16 帧在线重适应，**零篇量化可靠性**。
2. 前馈一侧（RenderFormer）参数化了光源，但作者自己列出 5 类越界失败（>8 光源、场景内光源、彩色光、大光源、高阶镜面），**全部只有定性展示**。
3. 最接近的先行工作 NRP（CGF 45(4), 2026）做的是"可交互可微重打光代理"，目标是**代理的可微性**，不是**响应的保真度**，且无公开代码。

**风险**：命题若写成"加梯度监督"，会被 Sobolev training（2017）直接盖住。
**建议命题**（更锋利）："在固定参考渲染预算下，单帧图像误差能否预测模型对光源变化的响应误差？若不能，主动选择扰动方向能否以更少预算降低响应误差？"
**关键实验设计**：必须用**成对采样（公共随机数）**估 `R(θ+δ) − R(θ)`，否则参考侧方差会吃掉全部信号；δ 要扫一条曲线（一阶=灵敏度、二阶=刚度）；预算按"参考渲染次数"对齐。

### 方向 B（有容差的焦散设计）——空白最硬，建议提前

**证据**：5 篇焦散逆设计，**0 篇报告容差曲线**。最强的 TVCG 有 CNC 实物也只做定性。
**你的贡献可以是**：首次给出（清晰度、效率、容差）的 Pareto 面 + 最坏情形保证 + 对抗式扰动搜索。理论锚点用 étendue/亮度守恒。
**风险**：审稿人会说"这是 robust optimization"。回答只能靠渲染/光学特有结构（自由曲面参数化、可微渲染梯度、感知度量、内层 max 的高效求解）。

### 方向 C（自适应光线—波动）——空白明确，但别现在碰

**证据**：wave tracing 已能处理衍射/偏振/多次散射，但**跨路径相干（散斑）明确不支持**；gratnet 只能做空间平稳表面。没有任何工作做"何时切换"的误差判据。
**判决**：12 个月内不做主线。若 B 涉及衍射光学元件，可作为 B 的自然延伸。

## 6. 两周内能做完的第一步

1. 用 Mitsuba 3 搭 3 个场景（漫反射墙 + 光滑金属 + 玻璃焦散），固定相机，扫一盏面光源的 5×5 位置网格，**成对采样**渲染参考序列（高 spp，作为 GT）。
2. 拿 RenderFormer V1/V2 权重直接推理这 25 个光源位置，测：
   - 单帧误差（PSNR/LPIPS）
   - **响应误差**：`‖ΔÎ − ΔI‖` 随 δ 的曲线
   - Jacobian 余弦相似度（有限差分 vs 网络自微分）
3. 判据：**能否找到一对配置，单帧 PSNR 差 <1 dB 但响应误差差 >3×。**
   - 找到 → A 的命题成立，进入方法设计（主动扰动选择 + 响应监督）。
   - 找不到 → 说明单帧误差够用，A 应放弃，转 B。
