# 宏观光渲染研究 Idea 意见报告

日期：2026-11-06。面向项目后续开发与选题决策。

项目目标是利用现有 RTX 5090 服务器开展宏观场景光照与渲染研究。光镊提供可控扰动、响应测量和稳定性分析的启示；项目不以微粒操控、光学力仿真或搭建光镊硬件为目标。

**建议优先验证方向 A，即有限物理渲染预算下的光源编辑响应学习；方向 B 的鲁棒焦散设计作为备选；方向 C 的波动光学精度选择暂缓。** 三个方向目前都是研究假设，没有本项目实验结果证明优势。导数监督、神经缓存残差修正、学习式缓存混合和光线与波动混合均有先行工作，不能单独作为创新主张。

**一 项目范围与现有资产**

讨论从图形学如何处理光、光镊实验及其启示开始，随后根据硬件与兴趣约束，收敛到宏观光渲染。当前资料包括 26 篇核心论文的 PDF 与逐页文本、来源索引、开源仓库及项目页记录、初始调研笔记和检索脚本。新的关键补充文献以本报告中的链接保存，不计入原 26 篇 PDF 集合。

本项目尚未实现候选算法，未训练模型，未在 5090 服务器上验证环境或吞吐量。服务器适合开展小规模合成数据、参考渲染和神经代理试验的判断是一项工程建议，不是对具体场景显存或实时帧率的承诺。

研究对象以几何光学、路径追踪及其学习式近似为主。涉及衍射与相干效应时，需采用适用的波动模型；仅通过图像后处理不能证明波动光学正确性。

**二 已有工作对选题的约束**

| 近邻工作 | 原文支持的能力 | 对本项目的限制 |
|---|---|---|
| [RenderFormer V1](../pdf/renderformer-2025.pdf) 与 [V2](../pdf/renderformer-v2-2026.pdf) | 从场景描述预测图像；V2 扩展透明材质、焦散、体积、环境光等，局限中说明未显式约束时间一致性 | 不能用 V1 能力边界概括 V2；连续编辑响应是可评估问题，但局限陈述不自动构成新方法 |
| [RenderFormer++](../pdf/renderformer-plus-2026.pdf) | 引入光传输相关先验与特征空间的传输一致性损失 | 仅提出物理约束或传输一致性不足以证明创新 |
| [Neural Two-Level Monte Carlo](../pdf/ntmc-2024.pdf) | 以神经缓存近似与物理残差积分组合构造估计器，包括消除缓存偏差的方案 | 神经近似加物理修正已有直接先例 |
| [Sobolev Training](../pdf/sobolev-2017.pdf) | 对函数值及其导数共同监督 | 加梯度损失本身不是新贡献 |
| [DeepLight 2026](https://arxiv.org/html/2601.09439v1) | 用方向导数监督训练组织光传输代理，评估导数准确性与泛化 | 虽然任务不同，函数值准确不等于导数准确，以及随机方向监督的基本论证已有先例 |
| [Neural Render Proxies 2026](https://studios.disneyresearch.com/2026/07/01/neural-render-proxies-for-interactive-and-differentiable-lighting/) | 固定相机与材质场景的交互重打光，分离路径采样与发射计算，支持梯度式光源优化 | 快速可微重打光代理不是空白；必须比较额外的采样或编辑收益 |
| [Radiance Caching for Differentiable Path Tracing 2026](https://rgl.epfl.ch/publications/Zhang2026Cache) | 学习空间混合场，在缓存与继续追踪的估计器之间局部选择，服务材质和光照反演 | 给缓存增加可信度开关或学习混合权重已有近邻 |
| [面光源焦散设计](../pdf/caustic-surface-light-2025.pdf) | 建模有限面积发光体并设计自由曲面，有物理原型 | 将点光源替换为面光源不足以构成创新 |
| [Wave Tracing](../pdf/wave-tracing-2025.pdf) | 波动光学路径积分，以及弱局部传输和椭圆锥追踪的实际构造 | 需区分通用理论和实际表示的适用范围 |
| [Ray-Wave Hybrid Cloth 2025](https://doi.org/10.1145/3763359) | 光线模拟、波动模拟校准和孔径衍射结合的织物模型 | 混合几何与波动光学本身已有具体图形学实现 |

补充检索还确认了 [Neural Differential Radiance Field](https://www.cs.umd.edu/~saeedhd/) 这一直接相关的学习微分空间工作。当前仅确认作者页面列出的工作身份，尚未完成其全文方法核查；正式确定 A 的方法贡献前必须补读，不能据标题推断其已解决或未解决的问题。

**三 对初始笔记的修订意见**

[PROGRESS.md](PROGRESS.md) 保留为初始分析记录，其强结论不应直接用于提案或论文。

| 初始判断 | 当前意见 |
|---|---|
| 图已经能算得很好，响应可靠性几乎没人研究 | 渲染质量、采样效率和复杂光传输仍有困难；已有导数学习、缓存修正和可靠性相关研究。应围绕一个具体编辑任务查缺口 |
| 多数方法不输入光源参数，所以动态光都只能依赖若干帧重训练 | 混淆采样复用、在线缓存和前馈网络。参数可能由当前场景状态体现，不能据输入形式推断统一的适应延迟 |
| 五篇焦散论文没有容差曲线，因此首次容差研究是明确空白 | 有限论文集合不能证明整个领域缺失。需覆盖自由曲面光学、公差分析和制造误差优化 |
| 图像的二阶导数对应光镊刚度 | 缺少物理映射。图像不是势能，不能把响应曲率称为力学刚度 |
| 对抗式扰动搜索给出最坏情形保证 | 有限搜索只能得到已发现的最坏样本；全域保证需要额外认证或理论界 |
| 共用随机种子即可获得可信响应标签 | 公共随机数可能降低方差，但路径重映射与可见性变化会影响耦合，必须测量噪声底 |
| 参考渲染次数相同就是公平预算 | 每次渲染的样本数、路径长度、梯度和配对计算开销不同，应同时记录物理采样量与总时间 |

自由曲面光学已有[平移和旋转误差容限分析](https://www.sciencedirect.com/science/article/pii/S0030402618316310)，以及[基于关键光线的自适应公差分析](https://arxiv.org/abs/2407.03688)。这些工作不等于已解决本项目的目标图案鲁棒优化，但足以否定把容差整体视为新领域的说法。

**四 方向 A 有限预算下的光源编辑响应学习**

设物理渲染结果为 R(θ)，θ 表示光源位置、朝向、尺寸等参数。一次编辑 δ 的真实响应为：

```text
ΔR(θ, δ) = R(θ + δ) − R(θ)
```

核心问题是：在固定参考渲染成本下，如何选择编辑方向、编辑幅度及每对图像的采样量，使代理模型更准确地预测实际光照变化，并改善交互编辑或光源反求？

小幅编辑可用局部导数描述，大幅编辑可能跨越遮挡边界或高光区域。单纯提高图像平滑性会掩盖真实变化；单纯寻找变化最大的区域，又会把物理上正确的高灵敏度误当模型错误。需要区分真实响应大小、模型响应偏差和参考估计噪声。

候选方法是分阶段获取响应标签：以少量配对样本估计变化及噪声，在可见性变化、预测分歧或响应误差可能较大的编辑上进一步投入预算。可比较随机选择、误差估计引导和按成本分配三类策略。每一种策略都必须只使用训练时允许获得的信息；不能用测试集真值选择采样点。

候选训练目标可以组合图像损失与多幅度响应损失，但这种组合本身不作为创新主张。真正需要验证的是针对光传输的采样与估计策略，能否超越随机响应监督，以及同成本增加普通图像的效果。

| 近邻方向 | 可能的区别 | 必须证明的内容 |
|---|---|---|
| Sobolev 与 DeepLight | 面向有限幅度编辑，特别是可见性变化 | 优势不能仅由更多监督或普通方向导数训练解释 |
| Neural Render Proxies | 关注代理构建预算和编辑响应 | 在相同资源下改善编辑准确性或反求结果 |
| NTMC 残差校正 | 关注训练数据获取与响应估计 | 不能把残差补偿重新命名为新方法 |
| 学习式缓存混合 | 决策变量包含编辑方向与幅度 | 空间混合基线无法轻易得到同等收益，且额外开销计入预算 |

光镊启示在于受控扰动、方向性响应和噪声校准。图像一阶导数是参数灵敏度，二阶导数是响应曲率；不把它们直接解释成光学力或陷阱刚度。

**五 方向 B 具有指定容差的焦散设计**

目标是优化折射或反射表面，使目标图案在光源位置、接收面姿态或制造表面误差变化时保持质量。它与 A 的区别是：A 改进预测，B 改变物理结构；A 要正确预测变化，B 希望允许扰动下的目标图案保持稳定。

建议先限制为一个面光源和一个自由曲面，定义明确的扰动范围，例如相对于装置尺寸归一化的位置偏移及接收面角度。不要一开始同时引入所有制造误差、偏振、相干性和动态液面。

需要研究清晰度、能量利用效率和容差之间的权衡。候选贡献是以较低仿真预算寻找导致目标图案失真的扰动，并据此优化结构。必须与名义设计、随机扰动优化、规则网格采样，以及适用的公差分析或鲁棒优化基线比较。

有限面积光源建模与装配不确定性是不同问题。将光源面积扩大、添加随机噪声或画出一张 Pareto 图，本身未必形成方法贡献。搜索得到的最坏扰动只能称为经验结果；模拟的制造误差也不能替代真实加工与测量。

此方向可以只用服务器开展数值研究，但若要证明实物效果，需要后续加工与测量资源。当前将它放在 A 之后，原因是新颖性还需要跨到光学领域继续核查，且物理实证门槛更高。

**六 方向 C 面向特定材料的波动光学精度选择**

将问题收窄为织物透射或光栅衍射等一种现象：能否依据观察距离、像素覆盖范围、照明条件及材料参数，预测省略波动细节的图像误差，从而选择计算精度？

近景中明显的色彩和衍射细节，在远景中可能被像素积分平均。候选方法应按最终图像误差配置计算预算，并检查精度切换时的闪烁、亮度跳变、能量一致性及相干性假设。

不能把几何与波动结果随意做强度插值，宣称保留了干涉；也不能把通用 Wave Tracing 理论的能力全部归给某个近似实现。与既有混合材质模型和外观细节层次选择的区别，需要进一步方法级检索。

该方向改变光传输模型与精度选择，A 改变学习和采样，B 改变结构设计。C 对波动模型及参考解的验证要求最高，建议待 A 的实验基础建立后再考虑。

**七 第一阶段实验方案**

先固定几何、材质与相机，只编辑一个面光源。建立漫反射间接光、移动软阴影和镜面高光三类小场景。完成参考噪声校准后，再考虑焦散；不要将模型本来不支持的材质用作主要失败证据。

| 实验组 | 目的 |
|---|---|
| 仅图像监督 | 基础代理模型 |
| 图像加随机响应监督 | 验证普通响应监督的收益 |
| 图像加主动响应采样 | 验证候选采样机制的额外作用 |
| 相同额外成本增加普通训练图像 | 排除只因花费更多物理渲染成本产生的收益 |

参考图像使用线性辐亮度与固定曝光进行响应分析。显示用色调映射单独处理，不能让自动曝光造成的差异进入物理响应标签。参数位置、角度、尺寸量纲不同，必须记录归一化尺度，并在多个幅度下测试。

采用独立随机重复估计噪声底和统计不确定性。公共随机数可作为方差降低手段，但不能代替验证。响应接近零时，相对误差会不稳定，应同时报告绝对误差，并明确相对指标的分母下限或信号阈值。

训练与测试分开编辑轨迹；跨场景结论需要独立场景划分。分别报告平滑区域、可见性变化区域和高光区域，避免大面积平滑区域掩盖关键失败。在线采样或测试时适应需要单列协议与预算，不能与完全冻结的模型混合比较。

| 指标 | 回答的问题 |
|---|---|
| 图像误差及适用的感知指标 | 单帧是否准确 |
| 多幅度响应绝对误差与有保护的相对误差 | 编辑造成的变化是否准确 |
| 区域分解与误差分布 | 改善发生在哪里，是否只改善容易像素 |
| 参考渲染时间、样本量、训练时间与推理时间 | 收益是否值得额外成本 |
| 光源反求的最终误差、失败率与总时间 | 响应改善是否转化为下游价值 |

预算按端到端实测时间与物理采样量共同报告，固定训练预算并记录额外开销。不要预设某个 PSNR 或误差倍率作为普适成败阈值。继续条件是候选方法在独立测试中稳定超过随机响应监督与更多普通数据，收益超过参考噪声，并改善至少一个实际编辑或反求任务。

如果优势仅来自额外数据、仅存在于训练场景、或在计入采样开销后消失，应调整或放弃当前方法主张。如果仅发现响应失真而没有有效修正方法，可以形成诊断研究，但需要足够系统的评估和合理基线，不能包装成算法性能突破。

**八 开发顺序与近期交付**

1. 检查服务器环境并完成单场景参考渲染与梯度验证，保存版本和配置。
2. 建立配对编辑数据生成、参考噪声评估及独立轨迹划分。
3. 训练小型代理并完成四组公平比较，不从头训练通用大模型。
4. 加入光源反求任务，检查误差下降是否转化为实际收益。
5. 根据证据决定接入 RenderFormer、NRP 类代理或缓存系统，并补读直接相关文献。

近期交付应包括可运行的数据脚本、场景配置、训练与评估入口、误差及成本曲线和负结果记录。完整环境及迁移步骤见 [异地开发交接](../DEVELOPMENT.md)。

**九 当前决策**

| 方向 | 当前优先级 | 最值得检验的问题 | 最大风险 |
|---|---|---|---|
| A 光源编辑响应学习 | 优先验证 | 在同成本下，方向与幅度的主动采样能否改善真实编辑 | 被普通响应监督或更多训练数据解释 |
| B 鲁棒焦散设计 | 独立备选 | 能否更经济地获得质量、效率与容差的权衡 | 与光学公差及鲁棒优化重叠，实物验证需求 |
| C 波动精度选择 | 暂缓 | 何时省略波动细节仍满足图像误差要求 | 参考解、相干性和切换一致性难验证 |

正式提案应以具体问题、方法机制和可复现实验为中心。光镊作为启发来源保留，但不作为新颖性证明，也不把研究计划写成已经取得的结果。
