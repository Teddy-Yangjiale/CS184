# 南方科技大学（SUSTech）图形学相关老师调研

调研日期：2026-11-04
范围：计算机科学与工程系（CSE）为主，附带创新创意设计学院。
依据：SUSTech 官方院系师资页、个人主页、院系新闻。公开页面没有明确写“计算机图形学/渲染”的导师，以下是**最接近图形学**的方向。

## 结论先说

- **经典图形学（3D 重建、几何计算、物理模拟、布料/服装）**：**有一位非常匹配——李韧（Ren Li，2026 年加入）**。他的主页明确写的是 3D vision/digitization、geometric computing、physics-based simulation。
- **其他最接近图形学的是**：
  1. **马昱欣** — 数据可视化 / 可视分析（可视化是图形学的重要分支）
  2. **郝祁** — 3D 视觉、结构光、自动驾驶感知、VR 相关
  3. **张建国** — 计算机视觉、多模态大模型、医学图像
  4. **刘江** — 医学成像 AI、AR/VR 应用（多媒体课程）
  5. **于仕琪** — 计算机视觉、生物特征（步态识别）
  6. **郑锋** — 计算机视觉、跨媒体智能、HCI
- **偏 AR/VR/交互设计**：创新创意设计学院有 XR、交互设计、数字媒体方向，但不是渲染/几何内核研究。

## 四、如果你想做“经典图形学”，怎么办

SUSTech 目前公开师资里，**做 3D 重建/几何/物理模拟** 最直接的是 **李韧**；但如果你要做的是**离线渲染器、路径追踪、几何处理理论、角色动画**，他的方向仍偏 3D vision + physics-based reconstruction，不完全等同经典渲染/动画。可以考虑：

1. **先联系李韧**：3D 重建、几何计算、布料/服装模拟、物理仿真、生成式 3D。
2. **其他相邻方向**：可视化（马昱欣）、3D 视觉/感知（郝祁）、医学成像（刘江/张建国）、CV（于仕琪/郑锋）。
3. **找联合指导/暑期科研**：联系国内图形学强组（浙大 CAD&CG、清华、中科大、HKUST、CUHK、CityU、NTU 等）做暑研/远程合作。
4. **自学 + 作品集**：path tracer、3DGS viewer、流体/布料模拟、mini renderer；申请时比“上过课”更有说服力。
5. **邮件联系策略**：
   - 先读对方 2–3 篇论文；
   - 邮件里写清楚你学过 CS184、做过什么、想解决什么问题；
   - 附 CV、GitHub、作品图/视频；
   - 不要群发模板。
