## 四、怎么选：一句话版

- **想稳且效果好看**：Volumetric Scattering、Subsurface Scattering、Cloth Rendering、2D Fluid、Light Field Camera。
- **想要工程亮点/作品集**：GPU Path Tracer (OptiX)、CUDA/Shader Cloth、Font Rendering、GPU Fluid。
- **想冲 Showcase**：BDPT + MIS、Progressive Photon Mapping、Rendering Glints、Iridescent Path Tracing。
- **想低风险起步**：Add Texture Support、NPR、Shaders Only、Solid Texture Synthesis；但必须加一个自己的扩展，否则 4 人 4 周工作量偏少。
- **不要选**：纯游戏/纯 UI、没有图形学技术含量的项目；官方 FAQ 明确要求必须有 graphics 技术成分。

更多分析见 `recommendations.md`。
