# 图形学在关注什么：2026 版地图

整理日期：2026-11-04
定位：给正在学 CS184、想了解研究前沿的人一份“能做什么 / 不能做什么 / 往哪走”的概览。

---

## 0. 一句话总结

图形学正在从**“手工建模 + 物理渲染”**，转向**“捕获/生成 + 神经表示 + 物理约束 + 实时交互”**。

但底层没有变：
- 光栅化、光线追踪、采样、变换、几何、着色、模拟仍然是地基。
- 新方法大多是在这些地基上换表示、换优化方式、换硬件。

---

## 1. 2026 图形学的六块地图

### A. 渲染（Rendering）
- 离线路径追踪：电影/VFX 级真实感
- 实时渲染：光栅化 + 光追效果 + 神经降噪/超分
- 材质与外观：BRDF、微表面、次表面散射、布料、毛发
- 体积渲染：烟、雾、云、火
- 光谱/偏振渲染：更物理，但更贵
- 神经渲染：NeRF、3D Gaussian Splatting、神经纹理

### B. 几何与 3D（Geometry / 3D）
- 3D 重建：多视图立体、photogrammetry、NeRF、3DGS
- 生成式 3D：文本/图像 → 3D 资产
- 几何处理：简化、重网格、细分、参数化、布尔、CAD
- 表示：网格、点云、体素、隐式表面、Gaussian、神经场
- 动态/4D：动态场景重建、4D Gaussian

### C. 动画与模拟（Animation / Simulation）
- 角色动画：运动匹配、RL、运动学、IK
- 物理模拟：刚体、布料、毛发、流体、烟、断裂、接触
- 数字人：人脸/身体/毛发/服装捕获，音频驱动 avatar
- 神经模拟：神经算子、可微物理、Gaussian 流体

### D. 成像与显示（Imaging / Display）
- 计算摄影：HDR、burst、夜景、去噪、重对焦
- 光场/全息：光场相机、全息显示
- VR/AR：透视、眼动、变焦、 pancake 光学
- 传感器：事件相机、神经传感器、镜头设计

### E. AI 与生成（Generative / World Models）
- 图像/视频生成
- 文本/图像 → 3D、材质、纹理、动画
- 世界模型：可交互的神经场景/神经游戏引擎
- AI 辅助创作：代码、shader、资产、动画
- 神经降噪/超分/压缩

### F. 交叉领域（Interdisciplinary）
- 机器人：sim2real、可微仿真、抓取
- 自动驾驶：神经渲染、闭环仿真
- 数字孪生：城市/工厂/建筑
- 医疗：成像、手术模拟
- 制造：CAD/CAM、3D 打印
- HCI：AR/VR 交互、显示

## 2. 已经能做到的（2026 年状态）

### 2.1 电影/VFX 级离线渲染：成熟

能做到：
- 复杂场景的路径追踪：全局光照、焦散、体积、毛发、布料、水体、破坏
- 大规模集群渲染，单帧几分钟到几小时
- 与实拍合成，达到肉眼难辨的程度

代价：
- 算力、时间、艺术家调参
- 不是“一键生成”，而是大量手工/流程

### 2.2 实时渲染：光栅化 + 光追效果，成熟

能做到：
- 4K 60–120fps 的光栅化游戏
- 光追阴影/反射/环境光遮蔽
- 神经降噪 + 超分（DLSS/FSR/XeSS 类）
- 高端硬件上部分游戏/场景的实时路径追踪

边界：
- 完整路径追踪仍受分辨率、场景复杂度、硬件限制
- 实时 GI、体积、毛发、布料通常需要近似/预计算

### 2.3 3D 重建与 3DGS：从研究走向生产

能做到：
- 多张照片/视频 → 3D Gaussian Splatting / NeRF
- 实时自由视点浏览
- 静态场景、部分动态场景
- 与游戏引擎/VR 结合

边界：
- 反光、透明、无纹理、动态、大场景仍然难
- 内存/存储大，编辑和物理交互弱
- 不是“带语义、可编辑的 CAD 模型”

### 2.4 生成式图像/视频：非常强

能做到：
- 文本/图像 → 高质量图像、短视频
- 风格化、修复、扩图、换背景
- 作为概念设计和素材生成工具

边界：
- 长视频的时序一致性、物理合理性、精确控制仍难
- 版权、溯源、deepfake 风险

### 2.5 文本/图像 → 3D 资产：早期生产可用

能做到：
- 生成带几何 + 纹理的 3D 资产
- 用于游戏/AR 的草模、背景道具
- 图像 → 3D、多视图 → 3D

边界：
- 拓扑、UV、PBR、绑定、动画通常要人工清理
- 复杂结构、可动部件、物理属性仍不可靠
- 多视角一致性、尺度/物理正确性不足

### 2.6 数字人：工作室级成熟，消费级早期

能做到：
- 高精度人脸/身体/毛发/服装捕获
- 电影级数字替身
- 音频驱动 2D/3D avatar
- VR 中的实时表情/口型（有限场景）

边界：
- 照片级实时远程呈现仍难
- 头发、眼睛、皮肤微结构、服装接触、表情细节容易“恐怖谷”
- 多视角/长时间稳定性、轻量化头显仍是问题

### 2.7 物理模拟：VFX 成熟，实时近似

能做到：
- 布料、毛发、流体、烟、火、断裂、刚体
- 电影级离线模拟
- 游戏中的实时近似（布料、破碎、简单流体）

边界：
- 复杂耦合、接触、自碰撞、拓扑变化
- 实时高精度仍然非常贵
- 参数调优和稳定性仍是手艺

### 2.8 计算摄影：手机端成熟

能做到：
- 夜景、HDR、多帧降噪、人像虚化、超分
- burst photography
- 计算重对焦（光场）

边界：
- 物理极限（光子噪声、衍射、景深）
- 光场/全息消费级显示仍不成熟

### 2.9 逆渲染/可微渲染：受控场景可用

能做到：
- 从多视角/受控光照恢复几何、材质、光照
- 重打光、材质编辑
- 与 3DGS/NeRF 结合

边界：
- 随意拍摄的单图/视频仍然病态
- 反照率/光照/材质分解存在根本歧义
- 透明、镜面、次表面、动态场景很难

## 3. 仍然做不到 / 极难做到的

### 3.1 “Holodeck”：通用、实时、照片级、可交互、物理正确的开放世界

为什么难：
- 算力：完整光传输 + 复杂几何 + 体积 + 材质
- 内容：需要海量高质量 3D 资产
- 物理：接触、断裂、流体、布料、毛发耦合
- 语义：理解/编辑/交互
- 评价：没有统一标准

现实：只能在**受限场景、受限分辨率、受限交互**下做到部分效果。

### 3.2 一句话/一张图 → 生产级 3D 资产

为什么难：
- 单图本身有歧义（背面、内部、材质、尺度）
- 拓扑/UV/绑定/动画/物理属性不是“看起来像”就行
- 数据稀缺：高质量 3D 资产远少于图像/文本
- 评价困难：几何、纹理、物理、可用性要多维评估

现实：能生成“看起来不错”的 asset，但生产管线仍需人工清理。

### 3.3 随意视频 → 完美动态 3D 重建

为什么难：
- 遮挡、拓扑变化、快速运动、运动模糊
- 反光、透明、无纹理、重复纹理
- 相机标定/同步/曝光
- 大场景的存储与流式

现实：受控多相机/静态场景效果好；wild video 仍不稳。

### 3.4 实时精确模拟复杂耦合物理

为什么难：
- 高维状态、刚性方程、接触/摩擦/断裂
- 实时预算（16ms）与精度矛盾
- 参数/材质/尺度泛化
- 稳定性与艺术控制

现实：游戏用近似；VFX 用离线；实时高精度是研究前沿。

### 3.5 照片级实时数字人远程呈现

为什么难：
- 皮肤次表面、眼睛、毛发、微表情
- 服装/接触/自遮挡
- 捕获/编码/传输/渲染全链路
- 恐怖谷与感知评价

现实：工作室预录/离线可做到；消费级实时仍有明显差距。

### 3.6 通用逆渲染（材质/光照/几何完全解耦）

为什么难：
- 病态问题：不同组合产生相同图像
- 未知光照、未知相机、未知材质
- 镜面/透明/次表面/全局光照
- 需要先验/多视角/受控光照

现实：受控条件下可用；wild 条件下只能做近似。

### 3.7 生成模型的可控 3D 编辑与长时一致性

为什么难：
- 3D 一致性（多视角）
- 时序一致性（视频）
- 物理合理性
- 精确控制（布局、尺寸、材质、风格）
- 可编辑性（绑定、动画、语义）

现实：短片段/单物体可以；复杂场景/长时交互仍难。

### 3.8 物理可信的通用神经模拟

为什么难：
- 泛化到新材质/新边界/新尺度
- 物理守恒/稳定性保证
- 数据与监督
- 与渲染/控制闭环

现实：特定场景的 neural surrogate 很快；通用物理引擎仍是传统方法。

### 3.9 统一评价标准

为什么难：
- 感知质量 vs 物理正确 vs 可用性
- 3D 生成/重建/模拟各有指标
- 用户研究成本高
- benchmark 容易饱和/被刷

现实：PSNR/SSIM/LPIPS/FID 等只是代理指标；任务级评价更重要。

### 3.10 版权、隐私、安全与溯源

- 生成内容版权
- 数字人肖像/声音授权
- deepfake 检测
- 训练数据 provenance
- 水印/内容凭证（C2PA 类）

这些不是纯技术问题，但会深刻影响图形学产品。

## 4. 2026 正在发生的趋势

### 趋势 1：3D Gaussian Splatting 成为“通用显式表示”

- 静态/动态场景、avatar、SLAM、生成、压缩
- 与网格/物理/语义混合
- 优点：实时、可微、易训练
- 缺点：内存大、反射/透明/动态难、编辑弱

### 趋势 2：生成式 3D 与世界模型

- 文本/图像/视频 → 3D 场景/资产
- 可交互神经场景、神经游戏引擎
- 从“生成一张图”到“生成一个可探索的世界”
- 关键难题：一致性、物理、控制、长时稳定

### 趋势 3：实时路径追踪 + 神经降噪/超分

- 硬件光追 + 软件降噪 + 超分
- 高端游戏开始尝试完整路径追踪
- 神经渲染与传统渲染混合
- 目标：电影级光照进入实时

### 趋势 4：可微渲染与逆渲染

- 从图像/视频恢复几何、材质、光照
- 数字孪生、重打光、材质编辑
- 与 3DGS、NeRF、生成模型结合
- 关键：歧义、鲁棒性、尺度

### 趋势 5：数字人与远程呈现

- Gaussian avatar、神经毛发/皮肤/服装
- 音频驱动、表情/口型/眼神
- VR/AR 社交、远程会议、影视预览
- 关键：真实感、实时性、轻量化、恐怖谷

### 趋势 6：物理模拟 + 机器学习

- 神经算子、可微物理、Gaussian 流体
- RL 角色动画、运动匹配
- sim2real、机器人/自动驾驶
- 关键：泛化、稳定性、物理保证

### 趋势 7：计算成像与新型显示

- 光场、全息、事件相机
- VR/AR 光学（pancake、varifocal、视网膜级）
- 神经传感器/神经镜头
- 关键：物理极限、体积、功耗、成本

### 趋势 8：AI 辅助创作

- 文本/草图 → 资产、材质、动画、shader
- 代码生成 + 图形 API
- 人机协作而非全自动
- 关键：可控性、可编辑性、版权

### 趋势 9：效率与部署

- 蒸馏、量化、剪枝、稀疏化
- 移动端/XR 实时
- 流式 3D、压缩、LOD
- 关键：质量/延迟/功耗/内存的平衡

### 趋势 10：评价、数据与可复现

- 3D 资产/场景数据集
- 物理可信度/感知质量指标
- benchmark 与挑战赛
- 开源代码/数据
- 关键：避免“刷榜”，强调真实任务

## 6. 对学 CS184 的人意味着什么

### 6.1 基础仍然最重要

- 光栅化/光线追踪/采样：所有新方法都要用
- 变换/投影/相机：3DGS/NeRF/生成 3D 都要用
- 几何/网格/曲线：资产管线的基础
- 着色/BRDF/渲染方程：神经渲染也要懂物理
- 模拟/数值方法：物理 + ML 的基础
- 概率/统计：蒙特卡洛、扩散模型、神经渲染

### 6.2 值得动手的项目

1. 写一个 path tracer（HW3 已开始）
2. 写一个 3DGS viewer / 训练小场景
3. 写一个流体/布料模拟
4. 写一个神经场/NeRF 小实现
5. 做一个生成 3D / 逆渲染小实验
6. 读一篇 SIGGRAPH 论文并复现

### 6.3 选择方向

- 喜欢物理/渲染：path tracing、体积、材质、光谱
- 喜欢几何/建模：3DGS、重建、生成 3D、CAD
- 喜欢动画/物理：数字人、布料、流体、RL
- 喜欢成像/硬件：计算摄影、光场、VR/AR
- 喜欢 AI：神经渲染、生成 3D、世界模型
- 喜欢系统/性能：实时渲染、GPU、降噪/超分

### 6.4 不要把“生成”当全部

生成模型很强，但：
- 生产管线需要几何、拓扑、UV、绑定、物理
- 真实感需要渲染/材质/光照
- 交互需要实时/物理/系统
- 评价需要感知/任务指标

**图形学的核心价值**：不仅“看起来像”，还要“几何对、物理对、可编辑、可交互、可解释”。

## 8. 术语速查

| 术语 | 含义 |
|---|---|
| NeRF | 神经辐射场，用 MLP 表示场景，体积渲染 |
| 3DGS | 3D Gaussian Splatting，显式高斯点表示，实时 |
| 4DGS | 动态 3D Gaussian |
| Inverse Rendering | 从图像反推几何/材质/光照 |
| Differentiable Rendering | 渲染过程可求导，用于优化 |
| World Model | 可预测/生成环境状态与交互的模型 |
| Digital Human | 数字人/avatar |
| BSSRDF | 次表面散射 |
| BRDF | 双向反射分布函数 |
| MPM | 物质点法，常用于雪/沙/流体 |
| Sim2Real | 仿真到现实迁移 |
| Neural Operator | 学习函数到函数的映射，用于 PDE |
| C2PA | 内容来源/真实性凭证标准 |
