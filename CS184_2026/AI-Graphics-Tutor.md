## 四、图形学学习中最值得用视觉模型的 7 件事

### 1. 读课件里的“图”
CS184 很多关键概念是图：光栅化管线、采样网格、BRDF 半球、相机投影、Bézier 控制点、半边结构、BVH 划分。

**用法**：截图单页 → 让模型先“描述图中每个符号/坐标轴”，再推导公式。

### 2. 理解公式和几何直觉的对应
例如：
- 为什么透视除法要除以 w？
- 为什么重心坐标能插值属性？
- 为什么路径追踪的 pdf 要除以采样概率？
- 为什么微表面 BRDF 有几何项/菲涅尔项？

**用法**：让它同时给“直觉版”和“数学版”，再让它指出两者对应关系。

### 3. 诊断渲染 artifact
Path tracer 出图常见问题：fireflies、噪声、色偏、阴影漏光、法线错误、UV 错位、Z-fighting。

**用法**：给“你的图 + 参考图 + 关键代码 + 场景参数”，让它按可能性排序原因，并给最小复现实验。

### 4. 检查空间/坐标变换
世界坐标 → 相机坐标 → NDC → 屏幕坐标，是图形学最容易绕晕的部分。

**用法**：给一张 3D 示意图，让它写出完整矩阵链，并用一个具体点验证。

### 5. 读论文图表
SIGGRAPH / PBRT 的图往往信息密度很高。

**用法**：让模型解释坐标轴、实验设置、baseline、指标含义，再总结“这张图证明了什么”。

### 6. 生成练习题 / 自测
看完一讲后，让模型根据课件图出 5 道概念题 + 2 道计算题，并给答案。

### 7. 对照代码理解算法
把 shader / path tracer 的关键函数和输出图一起给模型，让它把变量映射到图中的量。

## 五、直接可用的 Prompt 模板

### 模板 A：读一张课件图

```text
你是我的 CS184 图形学助教。请看这张课件图，按以下结构讲解：
1. 图中每个符号、坐标轴、颜色/箭头分别代表什么；
2. 这张图想说明的核心公式或算法；
3. 逐步推导（不要跳步）；
4. 用一个具体数值例子验证；
5. 初学者最常见的 3 个误解。
如果图中有看不清的标签，请明确说“看不清”，不要猜。
```

### 模板 B：诊断渲染结果

```text
这是我的 path tracer 输出（图 1）和参考结果（图 2）。
场景/参数：___
关键代码：___
请：
1. 列出所有可见差异（噪声、firefly、色偏、阴影、几何、UV）；
2. 按可能性从高到低排序原因；
3. 对每个原因给出一个最小验证实验；
4. 指出哪一段代码最可能导致该问题。
```

### 模板 C：理解坐标变换

```text
根据这张图，用世界坐标、相机坐标、NDC、屏幕坐标四种空间描述每个变换。
请写出完整的矩阵链，并用点 p=(1,2,3) 逐步计算，指出每一步的 w 和透视除法发生在哪里。
```

### 模板 D：公式直觉 + 数学

```text
请用两种方式解释这个公式：
A. 直觉版：用图形学场景打比方；
B. 数学版：逐项推导每个因子的来源。
最后列出两者的一一对应关系，并指出这个公式在什么条件下不成立。
```

### 模板 E：自测

```text
根据这页课件，出 5 道概念题和 2 道计算题，难度接近 CS184 期中。
不要给答案；等我作答后再逐题批改，并指出我错在哪个概念。
```

## 六、使用技巧（很重要）

1. **裁剪 + 放大**：不要把整页 1080p 截图直接丢进去；把关键图裁出来，保证坐标轴/公式可读。
2. **给上下文**：告诉它“这是 CS184 第 14 讲辐射度量”“我们用的符号是 L_o, L_i, f_r”。
3. **要求它标注不确定**：视觉模型会“自信地看错”小字，要求它明确说看不清。
4. **多视角**：3D 图至少给 2–3 个角度；渲染 artifact 给局部放大图。
5. **数学必须验证**：让它给数值例子，你自己代一遍；不要直接背模型推导。
6. **双模型交叉**：Claude 讲直觉，GPT/Gemini 检查推导；两个答案不一致时回课本。
7. **保留错误日志**：把模型讲错的地方记下来，考前复习很有效。

## 七、局限

- **基准分数 ≠ 教学能力**：MMMU/MMMU-Pro 高，不代表它讲得清楚。
- **小字/坐标轴容易看错**：尤其是 PDF 缩放后的公式和下标。
- **数学推导可能“看起来很对”但一步错**：务必用数值例子验证。
- **渲染诊断需要代码和场景上下文**：只给图，模型只能猜。
- **排行榜变化很快**：以上为 2026-11-04 的快照，选型时以最新 leaderboard 为准。
